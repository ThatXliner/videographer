Turn motion into measurement

Track an object through a video, calibrate with a ruler, and export position data in centimeters.

Your video never leaves your device. Everything runs locally in this browser tab.

Tracking uses OpenCV's MIL tracker via OpenCV.js (about 10 MB, fetched once from jsDelivr). The command-line tool uses CSRT, so results can differ slightly.

Mark the reference stick

Tap or click each end of the ruler. Drag an end to fine-tune it.

Adjust the tick marks

Drag each tick onto the matching mark on the ruler. This corrects for lens distortion and perspective.

Select the object

Drag a box around the object you want to track. It must be visible in this first frame.

Choose a reference point

Pick which point on the box to measure. Tap a point or press 1 to 9.
